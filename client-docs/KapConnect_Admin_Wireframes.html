How Admin connects to the mobile app (simple)

  • Buyer app posts a coconut request → appears in Admin → Buy Requests.
  • Estate app posts a sell listing → appears in Admin → Sell Listings.
  • They negotiate & accept → becomes an Admin → Order.
  • If something goes wrong → Admin → Disputes.
  • New estate uploads documents → Admin → Verification → then Verified badge shows in the app.
